# Grilling założycielski: ukształtowanie destynacji mapy (2026-10-26)

Sesja założycielska wayfinder dla docelowej wersji `music-rater`. Runda 1 (Q1–Q4) — destynacja; runda 2 (Q5–Q11) — breadth-first po całej przestrzeni decyzyjnej. Odpowiedzi użytkownika skrótowo: `1a,2a,3a,4a` i `5a, 6b(+wzmianka o częstszym ocenianiu na telefonie), 7b, 8pełne gwiazdki, 9track-gain/skan, 10prostota, 11a`.

| # | Pytanie | Decyzja |
|---|---------|---------|
| Q1 | Czym kończy się mapa | (a) komplet decyzji + spec; budowa poza mapą, w zwykłych sesjach dev |
| Q2 | Gdzie żyje docelowa aplikacja | (a) przebudowa `music-rater` (vanilla JS); `song-scribe-rater` tylko źródłem wiedzy (parsowanie POPM, `music-metadata-browser`) |
| Q3 | Chmura | (a) pCloud; Google Drive wypada |
| Q4 | Tracker mapy | (a) lokalny markdown w `music-rater` (`.scratch/music-rater-target/`) |
| Q5 | Telefon (fakt) | (a) Android |
| Q6 | Rola telefonu | desktop główny, ale ocenianie na telefonie może stać się częstsze (pociąg, praca w tle) — mobile-first wysoki priorytet |
| Q7 | Interopoceny | (b) wymagany — rating ma być widoczny w innych narzędziach (foobar2000, MusicBee, odtwarzacze Androida) |
| Q8 | Skala ocen | pełne gwiazdki 1–5; brak oceny = brak tagu; bez stanu „odrzucone" |
| Q9 | ReplayGain | tylko track-gain; brak tagów → szybki skan w przeglądarce; wyniki cache'owane |
| Q10 | Konflikty ocen | prostota: last-write-wins, bez ostrzeżeń (pCloud trzyma historię wersji) |
| Q11 | Waveform | (a) pełny, klikalny/scrubowalny, z degradacją na słabych urządzeniach |

Fakty z rozpoznania (nie od użytkownika):

- Stary `music-rater`: odczyt `id3js`, zapis `browser-id3-writer`, pliki przez File System Access API; brak waveformu i ReplayGain.
- `song-scribe-rater`: React+Vite+shadcn, odczyt POPM przez `music-metadata-browser` (skala 0–255 → gwiazdki przez `/51` — do zweryfikowania w bilcie o POPM), a **zapis** oceny trafia do localStorage (brak zapisu do tagu w przeglądarce) — stąd problem „tagowanie nie działa do końca prawidłowo".
- Pliki testowe istnieją lokalnie w `D:\music\recordings\hi-q-recordings\` (MP3 + pliki `.asd` Rekordboxa).
